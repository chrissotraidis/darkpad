# DarkPad 0.1.1

DarkPad 0.1.1 keeps the game on its own window when the iPhone or iPad shows it in a resized window or on another display, and adds direct touch-control actions to the ••• menu.

## Fixed

- **Game window and external displays:** DarkPad placed SDL's window on the first foreground scene it found and kept it at the main screen's size and scale. In Split View, Stage Manager or on another display, such as a TV, the picture and touch coordinates could be sized for the wrong window, and nothing refitted them after a resize or display move. DarkPad now keeps SDL's window on the game's own scene, fits it to that scene when it rotates, resizes, moves display or returns to the foreground, and applies a chosen 50% or 75% render scale against the current screen.
- **Touch controls with a controller:** the ••• menu now has **Show Touch Controls** / **Hide Touch Controls** and a checked **Auto-hide Touch Controls with Controller** toggle. Show brings the controls back immediately with a controller still connected and keeps auto-hide off until you turn it back on. Only controllers with a full gamepad profile hide touch now, and controller state is checked again when DarkPad returns to the foreground.

## Get your copy

Rebuild with [PadMint](https://github.com/chrissotraidis/padmint/releases/latest) on an Apple Silicon Mac, or follow the [README](https://github.com/chrissotraidis/darkpad/blob/v0.1.1/README.md#get-darkpad). Install over the existing app with the same signing setup to keep saves and settings. Your own Perfect Dark (USA) Rev 1 / v1.1 ROM is imported in the app; no ROM is read during the build.

The only release attachments are `darkpad-v0.1.1-padmint.json` (PadMint's build recipe) and `SHA256SUMS`. No prebuilt IPA, game data, compiled game code, saves or signing files are published.

## Validation

- `tests/touch_visibility.c` (AddressSanitizer/UndefinedBehaviorSanitizer) covers the default Auto mode, saved On/Off, Show with a controller connected, editor and menu exceptions and the auto-hide toggle.
- A fresh PadMint build passed from the release source before tagging, using current PadMint main, Apple Python 3.9 and an empty PadMint folder.
- **Physical TV and controller acceptance is pending:** these changes have not yet been tried on an external display or with a physical controller.
